# DataMaps Open Source — локальный запуск

DataMaps позволяет искать организации в собственных CSV-файлах и выгружать результаты в XLSX. Локальный режим бесплатный: кредитов, подписки, платёжного аккаунта и API-ключа для этих функций не требуется. Код распространяется по [лицензии MIT](LICENSE).

В репозитории есть только **синтетический демонстрационный CSV**. База реальных организаций в публикацию не входит.

## Быстрый старт

Нужен Docker с Compose v2.

```bash
git clone https://github.com/Rauf-Ai/DataMaps-Open-Source.git
cd DataMaps-Open-Source
cp .env.example .env
```

Откройте `.env` и замените `SECRET_KEY=change-me-before-running` на случайное значение. Его можно получить командой `openssl rand -hex 32`. Затем запустите:

```bash
docker compose up -d --build
docker compose exec backend python /scripts/import.py
docker compose restart backend
```

Откройте [http://localhost:8090](http://localhost:8090). Демонстрационные организации уже доступны для поиска. Для выгрузки зарегистрируйте локальный аккаунт: подтверждение почты отключено. API-документация: [http://localhost:8090/api/docs](http://localhost:8090/api/docs).

## Свои данные

Импортёр принимает UTF-8 CSV с разделителем `;`, заголовком и 38 колонками по схеме в [`scripts/import.py`](scripts/import.py). Имя файла становится категорией. Укажите в `.env` абсолютный путь к папке с CSV через `CSV_SOURCE_DIR`, затем повторите импорт и перезапуск backend. Импорт заменяет прежний каталог. SQLite, DuckDB и выгрузки сохраняются в `data/`; эту папку стоит резервировать.

AI и живой поиск по картам требуют собственных ключей внешних провайдеров. Они не нужны для поиска по импортированным CSV и выгрузки XLSX. Платёжные маршруты в `LOCAL_MODE=true` отключены. Веб-интерфейс по умолчанию доступен только с этого компьютера через `127.0.0.1:8090`. Если порт занят, поменяйте `DATAMAPS_PORT` и `APP_URL` в `.env` вместе.
