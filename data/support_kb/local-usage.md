# Локальная работа с DataMaps

## Импорт CSV и поиск

Положите CSV-файлы с 38 колонками в папку, указанную как CSV_SOURCE_DIR в .env.
Запустите `docker compose exec backend python /scripts/import.py`, затем
`docker compose restart backend`. После этого откройте http://localhost:8090
и задайте фильтры поиска.

## Выгрузка в XLSX

Создайте локальный аккаунт и войдите. Подтверждение email для локальной установки
не требуется. Найдите организации, задайте число строк и нажмите «Выгрузить».
Файл можно повторно скачать из истории выгрузок до истечения срока ссылки.
Кредиты и оплата не нужны.

## Дополнительные функции

AI и живой поиск по картам требуют собственных ключей внешних провайдеров.
Поиск и выгрузка из импортированного CSV работают без этих ключей.
